# Ejercicio 2: Calculadora en C++

Este repositorio contiene el código fuente y las instrucciones para ejecutar una calculadora básica en C++, que realiza operaciones matemáticas simples: suma, resta, multiplicación, y división.

---

## 📋 Contenido

| Nombre                 | Descripción                                      |
|------------------------|--------------------------------------------------|
| `main.cpp`             | Código fuente de la calculadora en C++           |
| `README.md`            | Documentación e instrucciones para ejecutar      |

---

## 💡 Objetivo

Crear un programa en C++ que:

✔ Permita al usuario elegir una operación matemática  
✔ Realice la operación con dos números  
✔ Muestre el resultado en pantalla
